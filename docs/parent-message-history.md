# 학부모 문의 내역

`/parent/messages`에서 전체 문의, 중요 문의, 임시저장과 검색을 제공합니다. 문의 선택 시 `/parent/messages/:messageId`에서 날짜별 말풍선 대화를 확인합니다. 동일한 사안은 `/parent/messages/:messageId/follow-up`에서 대상 교사와 제목을 유지한 채 작성하고 기존 AI 분석·검토·전송 과정을 거칩니다. 상세 화면의 **새 문의 작성**은 빈 작성 화면을 열어 별도 문의 건을 생성합니다.

## 상담 상태

- 새 문의는 `before`(상담 전)로 생성합니다.
- 교사 답변 전송은 `inProgress`(상담 중)로 처리합니다. 완료는 교사 상세 하단의 **상담 완료 처리** 버튼으로만 수행합니다. 별도의 상담 시작 버튼은 없습니다.
- 완료된 문의에 추가 질문을 전송하면 `inProgress`로 전환하고 `needsTeacherReview`를 기록합니다. 교사 목록에 알림과 재확인 표시가 나타납니다.
- 상담 전·상담 중인 문의의 추가 질문은 대화에만 추가하고 상태와 재확인 표시를 바꾸지 않습니다.
- 학부모의 **확인했어요.**는 최신 교사 답변을 확인한 시각(`parentAcknowledgedAt`)만 기록합니다. 상담 상태와 재확인 표시는 바꾸지 않으며, 교사 상세에 `학부모 확인`으로 표시됩니다. 교사 답변이 없거나 이미 확인한 답변이면 비활성화됩니다.
- 교사 화면의 재확인 표시(`needsTeacherReview`)는 교사가 답변을 전송하거나 상담 완료 처리하면 해제됩니다.
- 학부모 화면의 재확인 표시는 별도 기준입니다. 학부모의 마지막 메시지 이후 교사 답변이 왔고 아직 **확인했어요.**를 누르지 않았을 때 목록과 상세에 표시됩니다.
- 추가 질문 자체로 AI 위험도를 높이거나 반복 민원으로 분류하지 않습니다. 기존 내용 기반 분석 흐름만 사용합니다.

## 저장과 연동 범위

현재 프로젝트의 기존 Mock API와 브라우저 localStorage를 사용합니다. 실서버 저장·권한 검증·푸시 알림을 제공하는 구현은 아닙니다.

- 문의와 임시저장은 로그인한 학부모의 userId별로 읽습니다. 다른 계정의 문의·임시저장 ID를 직접 입력해도 해당 계정의 화면에 노출하지 않습니다.
- 기존 단일 임시저장 키와 전송 데이터는 호환됩니다. 임시저장 컬렉션을 추가하여 여러 새 문의와 추가 문의 초안을 각각 복원합니다.
- 문의의 `status: SENT`는 전송 상태이고 `consultationStatus`는 상담 상태입니다. 대화 메시지는 `conversation`에 추가하며 원래 문의를 유지합니다.
- 동일한 작성 ID의 재전송은 중복 메시지를 만들지 않습니다.
- 교사 화면의 Mock 연결 정보는 `mockConnectedTeachers`에 정의되어 있습니다. 기본 학부모가 연결한 `teacher-102`는 테스트 교사 계정(userId 201)의 담당 교사입니다. 기존 교사 예시 목록도 유지합니다.
- 동일 브라우저의 교사 목록과 학부모 상세는 저장소 변경 및 탭 복귀 시 갱신됩니다. 교사 알림은 앱 내 재확인 안내입니다.
- 교사 상세 카드의 주제·내용은 대화 전체의 AI 요약(`conversationSummary`)입니다. 분석 API가 없어 학부모 문의는 키워드 기반 Mock 요약을 사용하며, 교사 답변으로 바뀌지 않습니다.

실제 API 연동 시에는 서버에서 학부모 소유권과 담당 교사를 확인하고, 추가 메시지 생성·완료 건 재개·교사 알림을 원자적으로 처리해야 합니다. 기존 대화의 AI 위험도는 별도 분석 결과로 관리해야 합니다.

## 검증

```bash
npm run build
npm run test:auth -- parent-message --workers=2
```

`tests/auth/parent-message-history.spec.ts`는 데스크톱·모바일에서 계정별 조회 범위, 상태 표시, 검색·중요 문의, 완료 문의 재질문과 중복 전송 방지, 교사 답변·명시적 완료, 새 주제 분리, 복수 임시저장과 모달 이어쓰기를 검증합니다. 기존 작성·AI 검토 테스트도 함께 실행합니다.
