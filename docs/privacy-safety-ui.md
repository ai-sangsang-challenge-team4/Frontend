# 개인정보 마스킹 및 안전 상태 UI (#13)

학부모 문의 작성·검토 화면에 기존 전화번호·이메일 마스킹을 연결하고, 교사 메시지 화면의 안전 안내와 재검토 흐름을 보완합니다. 공통 `Button`, `Badge`, `Modal`, 기존 메시지 상태·대응 가이드·처리 기록을 재사용합니다.

## 학부모 화면

- 제목·본문 입력 시 개인정보 탐지 건수와 접을 수 있는 마스킹 결과를 표시합니다. 개인정보 값 대신 `[전화번호]`, `[이메일]`을 표시합니다.
- AI 분석에는 마스킹된 본문만 사용합니다. 원문은 직접 비교·수정할 수 있도록 기존 초안에 유지합니다.
- 선택한 AI 초안이나 원문을 수정하면 마스킹 결과도 갱신합니다. 전송 직전에 제목·최종 본문을 다시 검사하고, 확인창과 전송 내역에는 가린 문장을 사용합니다.
- 마스킹 실패는 AI 수정안 생성 실패와 구분합니다. 마스킹 실패 시 검토 화면으로 넘어가지 않고 분석·전송 버튼을 비활성화합니다. 입력 유지, 직접 수정, 마스킹 재시도를 제공합니다.
- 마스킹에 성공한 뒤 AI 수정안 생성만 실패한 경우에는 기존의 원문 확인·전송 흐름을 유지합니다.
- AI 판단이 참고 정보임을 검토 화면에 표시합니다.

## 교사 화면

- 기존 Emergency 안내와 공식 절차 링크를 사용합니다. 긴급 단계 또는 `safetyLock` 상태에서는 답변 생성·전송 제한이 유지됩니다.
- 긴급 단계가 아닌 `safetyLock`도 별도 문구로 안내합니다. 위험도 수정이나 재검토 요청 자체로는 잠금이 해제되지 않습니다.
- 재검토 요청을 접수하면 대기 안내와 비활성화된 `재검토 요청 완료` 버튼을 표시하고, 동일 화면에서 중복 처리 기록을 남기지 않습니다. 위험도를 직접 수정할 권한과 재검토 요청은 구분합니다.
- `studentSafetySignal`의 `NONE`은 카드를 숨기고, `POSSIBLE`은 추가 확인, `URGENT_REVIEW`는 긴급 확인 문구와 배지를 표시합니다. 관련 원문 열람은 기존 권한 검사를 따릅니다.
- 답변 작성 화면에 AI 판단이 참고 정보임을 표시합니다.

## Mock 환경 및 연동 범위

현재 개인정보 탐지는 기존 로컬 규칙을 사용하며 **전화번호(휴대·일반·인터넷 전화), 이메일, 주민등록번호**만 처리합니다. 백엔드 `PiiMaskingServiceImpl`이 가리는 형식은 같은 순서로 모두 가리고, 점(.) 구분 번호처럼 서버가 가리지 않는 형식도 일부 더 가립니다. 서버는 받은 본문을 그대로 저장해 교사에게 보여 주므로 프론트가 서버보다 덜 가리면 안 됩니다. 050 개인 가상번호도 가리는데, 서버는 아직 가리지 않습니다. `pii-masking.spec.ts`가 서버 정규식을 복사해 결과가 같은지 확인하니, 백엔드 규칙이 바뀌면 함께 고쳐 주세요. 이름·주소 등 다른 개인정보까지 탐지한다고 보장하지 않도록 UI에 범위를 표시합니다. 원문·초안의 브라우저 저장 방식은 기존 Mock 구조를 사용합니다.

안전 상태는 기존 `ThreadAnalysis`를 사용합니다. 재검토 접수는 기존 교사 Mock 메시지와 같이 메모리에서만 관리되므로 새로고침하면 초기화되며, 실제 담당자에게 요청을 전송하지 않습니다. 서버 연동 시 마스킹 결과·실패 응답, 재검토 요청 저장·접수 상태, 지정 검토자의 잠금 해제 권한을 연결해야 합니다.

개발 서버에서 마스킹 실패는 브라우저 콘솔로 재현할 수 있습니다.

```js
localStorage.setItem('teacher-hub.pii-mock-settings', JSON.stringify({ failMasking: true }));
```

문의 작성 화면에서 `AI 분석 시작` 또는 검토 화면에서 `전송하기`를 누릅니다. 실패 상태와 차단을 확인한 뒤 아래 설정을 실행하고 `마스킹 다시 시도`를 누르면 복구합니다. 이 설정은 개발 모드에서만 적용됩니다.

```js
localStorage.removeItem('teacher-hub.pii-mock-settings');
```

## 검증

```bash
npm run build
npm run lint
npm run test:auth -- privacy-safety.spec.ts parent-message-review.spec.ts parent-message-write.spec.ts teacher-message-board.spec.ts teacher-reply-flow.spec.ts
```

`privacy-safety.spec.ts`는 제목·본문 마스킹, 분석 입력 보호, 수정 후 재검사, 확인창을 연 뒤 발생한 마스킹 실패, 실패 복구, Emergency·안전 잠금, 중복 재검토 요청, 학생 안전 신호 세 상태를 데스크톱·모바일에서 확인합니다.
